# Chessboard color scheme

Taking the standard (8x8) representation of a chessboard. It could be imagined as a 2D cartesian plane, with the x axis being represented by the alphabets, and y axis by the numbers. (**a1** is always **"Black"**)

Given coordinates in the form of string, print if that cell is white or black.

---

## Input

- ### Input format:
  First line contains a string s.

- ### Output format:
  White or Black.

- ### Constraints:
  |s|=2

- #### **Input:**
```python
b2
```
- #### **Output:**
```python
Black
```
